
#  InterviewAce
### Your AI-Powered Interview & Resume Preparation Companion

InterviewAce is an AI-powered web application built with Streamlit to help job seekers improve their resumes, prepare for interviews, and build confidence in their job search.

 **Live App:** https://miniproject321.streamlit.app/

---

##  Features

-  **Resume Summary Improvement** — Improve clarity and professionalism.
-  **Resume Bullet Generator** — Create stronger, more impactful bullet points.
-  **Resume Scoring** — Get AI-assisted feedback on your resume.
-  **Keyword Matching** — Compare resume keywords with job descriptions.
-  **Interview Preparation** — Generate practice interview questions.
-  **AI Assistant** — Get help with career preparation and professional writing.

---

##  Tech Stack

| Technology | Purpose |
|---|---|
| Python | Core programming language |
| Streamlit | Web application interface |
| Ollama | Local AI model runtime |
| Phi-3 Mini | Language model |
| FastAPI | AI gateway API |
| Uvicorn | Runs the FastAPI server |
| Cloudflare Tunnel | Connects Streamlit Cloud to the local gateway |
| Requests | HTTP communication |

---

##  Architecture

```text
User
 |
 v
Streamlit Community Cloud
 |
 v
Cloudflare Tunnel
 |
 v
FastAPI Gateway (Mac)
 |
 v
Ollama
 |
 v
Phi-3 Mini
```

The web interface is hosted on Streamlit Community Cloud, while the AI model runs locally on a Mac using Ollama.

FastAPI receives authenticated requests from the application and forwards prompts to Ollama. Cloudflare Tunnel provides a public HTTPS endpoint for the gateway.

```bash
pip install -r requirements.txt
```

```bash

```

##  Local AI Setup

Install Ollama from:

https://ollama.com/download

Download Phi-3 Mini:

```bash
ollama pull phi3:mini
```

Test the model:

```bash
ollama run phi3:mini
```

---

##  FastAPI Gateway

Install the gateway dependencies on your Mac:

```bash
pip install fastapi uvicorn requests
```

Start the gateway from the folder containing `gateway.py`:

```bash
export INTERVIEWACE_API_KEY="YOUR_SECRET_KEY"

python3 -m uvicorn gateway:app \
  --host 127.0.0.1 \
  --port 8000
```

Check the gateway:

```text
http://127.0.0.1:8000/health
```

Expected response:

```json
{"status":"ok"}
```

---

##  Cloudflare Tunnel

Start the tunnel in another Terminal window:

```bash
cloudflared tunnel --url http://127.0.0.1:8000
```

Copy the HTTPS URL generated by Cloudflare.

---

##  Streamlit Secrets

Open your Streamlit Community Cloud app settings and add these secrets:

```toml
AI_GATEWAY_URL = "https://YOUR-TUNNEL-URL.trycloudflare.com"
AI_GATEWAY_KEY = "YOUR_SECRET_KEY"
```

`AI_GATEWAY_KEY` must match the `INTERVIEWACE_API_KEY` configured on your Mac.

**Never commit real secrets or credentials to GitHub.**

##  Requirements

The Streamlit application uses dependencies listed in `requirements.txt`.

The local FastAPI gateway has its own dependencies:

```text
fastapi
uvicorn
requests
```

Keep the gateway dependencies separate from the Streamlit requirements unless the web application itself imports them.

---

##  Important Notes

- Your Mac must remain awake and connected to the internet for local AI features to work.
- Ollama, FastAPI, and Cloudflare Tunnel must be running.
- A temporary Cloudflare URL may change after restarting the tunnel.
- Update `AI_GATEWAY_URL` in Streamlit Secrets if the URL changes.
- AI-generated content should be reviewed for accuracy before use.
- Do not expose Ollama's local API directly to the public internet.

##  Troubleshooting

### AI features are not responding

- Check that Ollama is running.
- Verify that Phi-3 Mini is installed.
- Confirm that the FastAPI gateway is running on port `8000`.
- Confirm that Cloudflare Tunnel is active.
- Check the URL and API key in Streamlit Secrets.

### Deployment fails

- Check the latest Streamlit Cloud logs.
- Verify the packages in `requirements.txt`.
- Remove unused heavy dependencies.
- Check compatibility with the configured Python version.
